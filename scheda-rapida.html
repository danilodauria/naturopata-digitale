🪟 Windows

  1. Scarica …-Windows-x64.exe.
  2. Doppio clic sul file.
  3. Avviso di Windows → «Ulteriori informazioni» → «Esegui comunque».
  4. Fine: l'icona è nel menu Start.

Lo ZIP portatile non installa nulla: si scompatta e si avvia.

🍎 macOS

  1. Scarica il .dmg del tuo processore.
  2. Apri l'immagine disco.
  3. Trascina l'app in Applicazioni.
  4. Primo avvio: tasto destro → «Apri» → «Apri».

Se dice «danneggiata», è la quarantena: xattr -dr com.apple.quarantine "/Applications/Naturopata Digitale.app"

🐧 Linux

  1. .deb: sudo apt install ./Naturopata-Digitale-Linux-amd64.deb
  2. Oppure AppImage: chmod +x sul file.
  3. Avvia l'AppImage con doppio clic.
  4. Se manca una libreria: libfuse2t64 (Ubuntu 24.04).

📱 Telefono

  1. Apri il sito con Chrome o Safari.
  2. Menu del browser → «Installa app» oppure Condividi → «Aggiungi alla schermata Home».
  3. Conferma.
  4. Dopo la prima apertura funziona anche offline.

Se il file non parte

In ordine di frequenza reale: quasi sempre è il download, non il programma.

  • Scarica di nuovo il file: un download interrotto è la causa numero uno.
  • Confronta l'impronta SHA-256 con quella della release.
  • Windows: l'avviso SmartScreen non è un errore, scegli «Esegui comunque».
  • macOS: togli la quarantena con il comando qui sopra, una volta sola.
  • Antivirus: ripristina il file dalla quarantena, non disattivarlo.
  • Linux senza accelerazione grafica: avvia con --disable-gpu.

Verifica l'impronta

Windows (PowerShell):

Get-FileHash .\Naturopata-Digitale-Windows-x64.exe -Algorithm SHA256

Linux e macOS, con SHA256SUMS.txt nella stessa cartella:

sha256sum -c SHA256SUMS.txt
shasum -a 256 -c SHA256SUMS.txt
